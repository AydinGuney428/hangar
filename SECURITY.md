# Security Policy

This repository is a local educational lab. It does not target external systems and should not require secrets, credentials, or production data.

## Reporting a security issue

If you find a security weakness in the repository itself, please avoid publishing exploit details in a public issue before a fix is available. Describe the affected component, expected behavior, observed behavior, and a minimal reproduction.

## Safe contribution rules

- Do not commit credentials, tokens, private keys, or personal data.
- Do not add scanners or automation aimed at third-party targets.
- Keep examples reproducible against local test data.
- Prefer minimal proof-of-concept tests that demonstrate the bug without unnecessary offensive capability.
